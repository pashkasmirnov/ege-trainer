16.7. Неравенства с логарифмами по переменному основанию

Для репетитора: показать ответы

1. Что такое переменное основание

В неравенстве \(\log_{h(x)}f(x)\vee\log_{h(x)}g(x)\) основание \(h(x)\) само зависит от \(x\). Тогда монотонность логарифма заранее неизвестна: при \(h(x)>1\) логарифм возрастает, при \(0

2. ОДЗ

Для всех логарифмов в записи:

  • основание: \(h(x)>0\) и \(h(x)\ne1\);
  • аргументы: \(f(x)>0\), \(g(x)>0\);
  • знаменатели (если есть) не равны нулю.

3. Стандартный способ: два случая

Неравенство \(\log_{h(x)}f(x)>\log_{h(x)}g(x)\) равносильно совокупности двух систем:

СлучайСистема
основание больше единицы\(\begin{cases}h(x)>1\\f(x)>g(x)>0\end{cases}\)
основание между 0 и 1\(\begin{cases}0

Решения двух систем объединяют (совокупность). Для знака \(<\) в системах переворачивают знаки между \(f\) и \(g\); для нестрогих знаков добавляют равенство в соответствующее неравенство между \(f\) и \(g\), условия на основание остаются строгими.

4. Сравнение логарифма с числом

Число записывают как логарифм с тем же основанием: \(1=\log_{h}h\), \(0=\log_h1\), \(c=\log_hh^c\).

  • \(\log_{h(x)}f(x)>0\iff\) совокупность: \(\begin{cases}h>1\\f>1\end{cases}\) или \(\begin{cases}0

5. Приёмы приведения к одному основанию

  • Формула перехода: \(\log_ab=\dfrac{\log_cb}{\log_ca}\), в частности \(\log_ab=\dfrac1{\log_ba}\).
  • Степень в основании: \(\log_{a^c}b=\dfrac1c\log_ab\); для чётной степени \(\log_{a^{2n}}b=\dfrac1{2n}\log_{|a|}b\).
  • Степень в аргументе: \(\log_ab^{2s}=2s\log_a|b|\), поэтому при чётной степени пишите модуль.

6. Связь с рационализацией

На ОДЗ два случая объединяются в одно рациональное неравенство:

\(\log_{h}f-\log_{h}g\vee0\iff(h-1)(f-g)\vee0\), \(\ f>0,\ g>0,\ h>0,\ h\ne1\).

7. Алгоритм решения

  1. Запишите ОДЗ: основания \(h>0\), \(h\ne1\), аргументы больше нуля, знаменатели не нуль.
  2. Приведите логарифмы к одному основанию, если нужно; число запишите как логарифм с тем же основанием.
  3. Перейдите к двум случаям по основанию (\(h>1\) и \(0
  4. Решите получившиеся неравенства (методом интервалов), объедините решения случаев.
  5. Пересеките с ОДЗ и запишите ответ.
Лайфхак 1. Два случая или один множитель. Запись \((h-1)(f-g)>0\) заменяет два случая сразу: множитель \(h-1\) «сам» меняет знак при основании меньше единицы.
Лайфхак 2. Число — это логарифм. Для сравнения с единицей пишите \(1=\log_hh\), для сравнения с нулём \(0=\log_h1\): получите \((h-1)(f-h)\) и \((h-1)(f-1)\).
Лайфхак 3. Если основание — число, скобку \((a-1)\) опускать нельзя: она задаёт знак перехода.
Лайфхак 4. Нестрогое неравенство. Для \(\ge0\) и \(\le0\) нули числителя входят в ответ, если удовлетворяют ОДЗ, а нули знаменателя — нет; основание всегда строго положительно и не равно 1.
Частые ошибки.
  • Забывают ОДЗ при замене и пересечении решения с ней.
  • Не меняют знак неравенства при умножении на отрицательное выражение (например, на множитель, который на ОДЗ заведомо отрицателен).
  • Заменяют только на ОДЗ: переход корректен только тогда, когда важен лишь знак выражения.
