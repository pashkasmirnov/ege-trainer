Задание 19 · Задача с параметром

19.7. Использование симметрий

Для репетитора: показать ответы

1. Идея симметрии

Если уравнение (неравенство, система) не меняется при некоторой замене переменной, то оно «инвариантно» относительно этой замены. Тогда решения возникают парами: если \(x_0\) — решение, то и преобразованное значение — тоже решение.

Общий вид: если \(f(x)=f(g(x))\) и \(x_0\) — решение, то \(g(x_0)\) — тоже решение. Например, уравнение \(f(x)+f(c-x)=0\) инвариантно относительно замены \(x\to c-x\).

2. Чётность: замена \(x\to-x\)

Если левая часть уравнения \(F(x,a)=0\) — чётная функция по \(x\) (то есть \(F(-x,a)=F(x,a)\)), то вместе с любым решением \(x_0\) решением является и \(-x_0\).

  • Следствие 1. Если решение единственно, то оно равно нулю. Поэтому сначала подставьте \(x=0\) и найдите значения параметра, при которых 0 — корень.
  • Следствие 2. Нечётное число корней возможно только при наличии корня \(x=0\). Без него корни идут парами \(\pm x_0\), и число корней чётно.

Чётными бывают, например, выражения, в которые \(x\) входит только через \(x^2\), \(|x|\), \(\cos x\).

3. Алгоритм «симметрия + проверка»

  1. Найдите подстановку \(g\), относительно которой задача инвариантна, и решите уравнение \(x_0=g(x_0)\). Полученное значение \(X\) — единственный кандидат на единственное решение (для чётности \(X=0\)).
  2. Подставьте \(X\) в задачу и найдите соответствующие значения параметра \(a\).
  3. Проверьте каждое найденное \(a\): нет ли у задачи других решений. Если есть, такое \(a\) не подходит.

Симметрия даёт только необходимое условие. Достаточность нужно доказывать отдельно — обычно решением задачи или оценкой.

4. Как доказывают, что других решений нет

  • Метод оценки. Если при всех \(x\) верно \(f(x)\ge c\) и \(g(x)\le c\), то равенство \(f(x)=g(x)\) возможно только тогда, когда \(f(x)=g(x)=c\).
  • Сумма неотрицательных слагаемых равна нулю лишь тогда, когда каждое слагаемое равно нулю.
  • Известные оценки: \(x^2\ge0\); \(|x|+|1-x|\ge1\); \(|x-a|+|x+a|\ge2|a|\).

5. Симметрия на плоскости \((x;a)\)

Если пара \((x_0;a_0)\) — решение и уравнение инвариантно относительно замены \((x;a)\to(-x;-a)\), то решением является и пара \((-x_0;-a_0)\). Тогда фигуру, задающую решения, достаточно построить наполовину, а затем отразить относительно начала координат.

Если полученная фигура симметрична, достаточно исследовать половину и учесть симметричные значения параметра.

6. Что проверять при единственном решении

  • Является ли уравнение чётным по \(x\) (или инвариантным относительно другого преобразования, например \(x\to c-x\)).
  • Какое значение переходит само в себя: \(x_0=g(x_0)\).
  • Для найденных значений параметра: действительно ли решение единственное (оценка, монотонность).
Лайфхак 1. Единственное решение чётной задачи — это \(x=0\). Сначала подставьте \(x=0\), найдите значения параметра, а затем проверяйте каждое из них.
Лайфхак 2. Нечётное число корней — только с нулевым корнем. Если требуется «ровно три корня» для чётного уравнения, то один из корней обязан быть нулём.
Лайфхак 3. Симметрия — только необходимое условие. Каждый найденный кандидат \(a\) нужно проверить: либо решить уравнение, либо оценить обе части и показать, что других решений нет.
Лайфхак 4. Ищите «скрытую» симметрию. Уравнение вида \(f(x)+f(c-x)=0\) не меняется при замене \(x\to c-x\): тогда кандидат на единственное решение находится из условия \(x_0=c-x_0\), то есть \(x_0=\dfrac c2\).

Если x0 является корнем исходного уравнения, то и является его корнем. Значит, исходное уравнение имеет единственный корень, только если то есть x0  =  0. Подставим значение x  =  0 в исходное уравнение:

откуда либо либо или a  =  5.

При a  =  3 исходное уравнение принимает вид: x2  =  2|x|. Корнями этого уравнения являются числа −2; 0 и 2, то есть исходное уравнение имеет более одного корня.

При a  =  1 и при a  =  5 уравнение принимает вид:

При x < −2 это уравнение сводится к уравнению x2 + 2x + 4  =  0, которое не имеет корней.

При −2 ≤ x ≤ 2 получаем уравнение x2  =  0, которое имеет единственный корень.

При x > 2 получаем уравнение которое не имеет корней. При a  =  1 и при a  =  5 исходное уравнение имеет единственный корень.

Ответ: 1; 5.
