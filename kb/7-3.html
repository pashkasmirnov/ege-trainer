Задание 7 · Простейшие уравнения

7.3. Иррациональные уравнения

Для репетитора: показать ответы

1. Основные понятия

  • Иррациональное уравнение — уравнение, в котором переменная стоит под знаком корня.
  • Арифметический корень \(n\)-й степени из \(a\) — число, \(n\)-я степень которого равна \(a\).
  • Для чётного \(n\) подкоренное выражение должно быть неотрицательным, а значение корня — тоже неотрицательно. Для нечётного \(n\) корень определён при любом \(a\).

2. Три основных типа и равносильные переходы

ТипРавносильное уравнение или система
корень нечётной степени равен числу или выражению\(\sqrt[m]{f(x)}=a\iff f(x)=a^m\) (\(m\) нечётное, \(m\ge3\))
корень чётной степени равен числу\(\sqrt[n]{f(x)}=b\iff f(x)=b^n\) при \(b\ge0\)
квадратный корень равен выражению\(\sqrt{f(x)}=g(x)\iff\begin{cases}g(x)\ge0,\\ f(x)=g^2(x)\end{cases}\)

Для корня чётной степени вообще: \(\sqrt[n]{f(x)}=g(x)\iff\begin{cases}g(x)\ge0,\\ f(x)=g^n(x).\end{cases}\) Если уравнение сводится к такой системе, то условие \(f(x)\ge0\) выполняется автоматически (ведь \(f(x)=g^n(x)\ge0\)), и отдельно его проверять не нужно.

3. Алгоритм решения

  1. Определить тип уравнения (корень какой степени, чему равен).
  2. Возвести обе части в нужную степень, чтобы избавиться от корня, и решить получившееся уравнение.
  3. Для квадратного корня обязательно учесть условие \(g(x)\ge0\) — проверить корни по нему.
  4. Если решали без перехода к системе (возведением в квадрат), проверить найденные корни подстановкой в исходное уравнение.

4. Способы решения

  • Переход к равносильной системе (неравенство для правой части и уравнение без корня). Корни, удовлетворяющие системе, проверять подстановкой не нужно.
  • Возведение в квадрат с последующей проверкой подстановкой: способ даёт уравнение-следствие, и посторонние корни возможны.
  • Замена переменной. Выражение с корнем обозначают через \(t\), причём \(t\ge0\) для корня чётной степени. Например, для \(\sqrt{x+3}=t\) уравнение сводится к квадратному \(t^2-3t-10=0\); корень \(t=-2\) отбрасывают как отрицательный, из \(t=5\) получают \(x+3=25\), \(x=22\).
  • Учёт ОДЗ. Область допустимых значений находят до преобразований, а корни проверяют по ней. ОДЗ иногда сразу отсекает лишний корень.
Ошибка: возвели в квадрат и не проверили. Возведение в квадрат даёт посторонние корни. Например, в уравнении \(\sqrt{4+2x-x^2}=x-2\) после возведения получаются \(x=0\) и \(x=3\); при \(x=0\) левая часть равна 2, а правая \(-2\), поэтому \(x=0\) не подходит. Ответ: \(x=3\).
Ошибка: пропустили условие \(g(x)\ge0\). Без неравенства для правой части в ответе появляются лишние корни. Не забывайте и про ОДЗ подкоренного выражения.
Лайфхак 1. Сначала знак правой части. В уравнении \(\sqrt{f}=g\) сразу запишите \(g\ge0\). Если правая часть — отрицательное число, корней нет, возводить в квадрат не нужно.
Лайфхак 2. Корень нечётной степени — без проверки. Корень нечётной степени (например, кубический) определён для любых чисел, поэтому после возведения в нечётную степень посторонних корней не появляется.
Лайфхак 3. Равносильная система вместо проверки. Перейдя к системе \(g\ge0,\ f=g^2\), вы получаете только подходящие корни и не подставляете их в корень.
