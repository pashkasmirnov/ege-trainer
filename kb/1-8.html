1.8. Вписанные окружности

Для репетитора: показать ответы

1. Что значит «окружность вписана»

Окружность вписана в многоугольник, если она касается всех его сторон. Отрезки касательных, проведённых из одной вершины, равны. Центр вписанной окружности лежит на пересечении биссектрис углов многоугольника. Радиус, проведённый в точку касания, перпендикулярен стороне.

2. Треугольник

  • В любой треугольник можно вписать ровно одну окружность; её центр — точка пересечения биссектрис.
  • Площадь: \(S=pr\), где \(p\) — полупериметр, \(r\) — радиус вписанной окружности (то же, что \(S=\tfrac12Pr\) для периметра \(P\)). Отсюда \(r=\dfrac{S}{p}\).
  • Отрезок касательной от вершины до точки касания равен \(p-a\), где \(a\) — сторона, противолежащая этой вершине.
  • Для прямоугольного треугольника с катетами \(a\), \(b\) и гипотенузой \(c\): \(r=\dfrac{a+b-c}{2}\).

3. Четырёхугольник

  • Вписать окружность можно не во всякий четырёхугольник.
  • Свойство: если в четырёхугольник вписана окружность, суммы противоположных сторон равны: \(a+c=b+d\).
  • Признак: если в выпуклом четырёхугольнике суммы противоположных сторон равны, в него можно вписать окружность.
  • Площадь: \(S=\tfrac12Pr=pr\).

4. Частные случаи

ФигураВписанная окружность
Квадратесть всегда; центр — точка пересечения диагоналей
Ромбесть всегда; центр — точка пересечения диагоналей; \(S=\tfrac12Pr\)
Прямоугольник (не квадрат), параллелограмм (не ромб)вписать окружность нельзя
Трапецияесть, если сумма оснований равна сумме боковых сторон: \(AD+BC=AB+CD\); высота равна диаметру: \(h=2r\); центр — пересечение биссектрис

5. Как решать задачу №1 про вписанную окружность

  1. Отметьте точки касания и равные касательные отрезки из каждой вершины; обозначьте их буквами.
  2. Для треугольника выберите: площадь и полупериметр — \(r=\dfrac Sp\); прямоугольный треугольник — \(r=\dfrac{a+b-c}{2}\).
  3. Для четырёхугольника с вписанной окружностью запишите равенство сумм противоположных сторон — это уравнение для неизвестной стороны.
  4. Проведите радиусы в точки касания: они перпендикулярны сторонам, и получаются прямоугольные треугольники.
  5. Если центр лежит на пересечении биссектрис, используйте это для нахождения углов: центр видит угол \(90^\circ+\tfrac12\) третьего угла (для треугольника с центром \(I\): \(\angle AIC=90^\circ+\tfrac{\angle B}{2}\)).
Лайфхак 1. Площадь двумя способами. Формула \(S=pr\) в связке с любой другой формулой площади (через высоту, через две стороны и синус, по формуле Герона) почти всегда сразу даёт радиус.
Лайфхак 2. Высота трапеции — диаметр. Если в трапецию вписана окружность, высота равна \(2r\), а сумма боковых сторон равна сумме оснований: этих двух фактов обычно хватает для решения.
Лайфхак 3. Прямоугольный треугольник. Радиус вписанной окружности считайте по формуле \(r=\dfrac{a+b-c}{2}\): не нужно искать площадь и периметр.
Лайфхак 4. Проверяйте существование. Прежде чем использовать вписанную окружность в четырёхугольнике, убедитесь, что она вообще бывает: суммы противоположных сторон должны быть равны.
Частые ошибки.
  • Ожидают вписанную окружность у любого четырёхугольника. Она есть только у выпуклого четырёхугольника с равными суммами противоположных сторон.

Разобранные примеры

Пример 1

Найдите радиус окружности, вписанной в правильный треугольник, высота которого равна 45.

Решение

Радиус окружности, вписанной в равносторонний треугольник, равен одной трети высоты. Следовательно, он равен 15.

Ответ: 15.

Пример 2

Около окружности описана трапеция, периметр которой равен 40. Найдите длину её средней линии.

Решение

В выпуклый четырехугольник можно вписать окружность тогда и только тогда, когда суммы длин его противоположных сторон равны. Следовательно, сумма оснований трапеции равна полупериметру, то есть равна 20. Средняя линия трапеции равна полусумме оснований, поэтому она равна 10.

Ответ: 10.

Пример 3

Боковые стороны трапеции, описанной около окружности, равны 3 и 5. Найдите среднюю линию трапеции.

Решение

В выпуклый четырехугольник можно вписать окружность тогда и только тогда, когда суммы длин его противоположных сторон равны. Следовательно, сумма оснований трапеции равна сумме боковых сторон, то есть равна 8. Средняя линия трапеции равна полусумме оснований, поэтому она равна 4.

Ответ: 4.
